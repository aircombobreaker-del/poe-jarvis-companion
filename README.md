# 🛡️ PoE Jarvis Companion (รองรับทั้ง PoE 1 และ PoE 2)

ผู้ช่วย AI อัจฉริยะส่วนตัวสั่งการด้วยเสียงภาษาไทย สำหรับเกมเมอร์ **Path of Exile 1** และ **Path of Exile 2**  
เนทีฟเดสก์ท็อปแอปพลิเคชัน (PyQt6) ใช้งานง่าย กินแรมน้อย และตอบสนองไว

---

## 📥 ดาวน์โหลดโปรแกรมใช้งานทันที (ไม่ต้องติดตั้ง Python)

ดาวน์โหลดเวอร์ชันล่าสุดได้ที่หน้า 👉 **[GitHub Releases](https://github.com/aircombobreaker-del/poe-jarvis-companion/releases/latest)**

* 🪟 **สำหรับ Windows (.exe):**  
  ดาวน์โหลดไฟล์ `PoE_Jarvis_Companion_Windows.zip` แตกไฟล์แล้วเปิด `PoE_Jarvis_Companion.exe` เล่นได้ทันที  
  *(หาก Windows Defender SmartScreen แจ้งเตือน ให้กด **"More info" (ข้อมูลเพิ่มเติม)** แล้วกด **"Run anyway" (เรียกใช้ต่อไป)**)*

* 🍎 **สำหรับ macOS (.app):**  
  ดาวน์โหลดไฟล์ `PoE_Jarvis_Companion_macOS.zip` แตกไฟล์แล้วลาก `PoE_Jarvis_Companion.app` เข้าโฟลเดอร์ Applications  
  *(ดูขั้นตอนการเปิดใช้งานครั้งแรกด้านล่าง)*

### 🍎 วิธีเปิดใช้งานครั้งแรกบน macOS (แก้ Gatekeeper บล็อก)

เนื่องจากโปรแกรมเป็นโอเพนซอร์สอิสระที่ไม่ได้ซื้อใบอนุญาตนักพัฒนาของ Apple ในการเปิดครั้งแรก macOS จะมีหน้าต่างแจ้งเตือนด้านความปลอดภัย ให้ทำตามวิธีใดวิธีหนึ่งด้านล่างนี้ **(ทำแค่ครั้งแรกครั้งเดียว)**:

#### วิธีที่ 1: อนุญาตผ่านการตั้งค่าระบบ (แนะนำ)
1. เปิด **การตั้งค่าระบบ (System Settings)** บน Mac
2. ไปที่เมนู **ความเป็นส่วนตัวและความปลอดภัย (Privacy & Security)**
3. เลื่อนลงมาที่หัวข้อ **ความปลอดภัย (Security)** จะเห็นข้อความแจ้งว่า `"PoE_Jarvis_Companion" ถูกบล็อกไม่ให้ใช้...`
4. กดปุ่ม **`เปิดต่อไป` (Open Anyway)** แล้วใส่รหัสผ่านหน้าจอ Mac
5. กดปุ่ม **`เปิด` (Open)** ในหน้าต่างยืนยัน โปรแกรมจะเปิดขึ้นมาใช้งานได้ทันที

#### วิธีที่ 2: คลิกขวาเปิด (Control + คลิก)
1. กดปุ่ม `Control` ค้างไว้ แล้วคลิกที่ไอคอนแอป `PoE_Jarvis_Companion` (หรือคลิกขวา)
2. เลือกเมนู **เปิด (Open)**
3. จะมีหน้าต่างขึ้นมา ให้กดปุ่ม **เปิด (Open)**

#### วิธีที่ 3: ปลดล็อกผ่าน Terminal (1 บรรทัด)
```bash
xattr -cr /Applications/PoE_Jarvis_Companion.app
```

## 🌟 ฟีเจอร์หลัก (Key Features)

* 🎮 **สลับโหมดเกมคลิกเดียว:** สลับฐานข้อมูลและการวิเคราะห์ระหว่าง **Path of Exile 1 (`poedb.tw`)** และ **Path of Exile 2 (`poe2db.tw`)**
* 🧠 **สมองไฮบริด (Hybrid Brain):**
  * **Google Gemini Flash:** ฉลาด ไว (~1 วินาที) มีโควตาฟรี 1,500 ครั้ง/วัน พร้อมระบบตรวจนับโควตารายวันและรีเซ็ตอัตโนมัติทุกเช้า 07:00 น.
  * **Local LLM:** เชื่อมต่อ LM Studio / Ollama ได้ในเครื่อง ใช้งานฟรีไม่จำกัด พร้อมระบบดึงข้อมูลเกมสดจากเว็บอัตโนมัติ
* 👤 **ตั้งชื่อ AI และคำเรียกตัวคุณเองได้อิสระ:**
  * ตั้งชื่อ AI ตามใจชอบ (เช่น จาร์วิส, วิชั่น, ฟรายเดย์, อัลตรอน, น้องเมย์) พร้อม**ซิงค์คำปลุกไมค์อัตโนมัติ**
  * ตั้งคำเรียกตัวผู้เล่น (เช่น ท่าน, บอส, ลูกพี่, เสี่ย, หรือชื่อเล่นของคุณ) AI จะเรียกตามนั้นทุกประโยค
* 🎭 **เลือกสไตล์นิสัย AI ได้ 4 รูปแบบ:** สั้นกระชับเน้นเล่นไว (1-2 ประโยค), ปกติสุขุมสมดุล, เพื่อนเล่นสายเฮฮาไลฟ์สด, หรือจริงจังวิเคราะห์ลึก (Theorycraft)
* 🎚️ **ตัวตัดเสียงรบกวน/เสียงทีวี (Input Sensitivity แบบ Discord):**
  * ปรับจุดตัดเสียงได้สูงถึง 6,000 พร้อมหลอด VU Meter แสดงระดับเสียงไมค์สด
  * ระบบล็อกไมค์กันเสียงลำโพงสะท้อนอัตโนมัติ (Anti-Echo Speaker Lock) ขณะที่ AI กำลังพูดตอบ
  * ปุ่ม **`⚡ คุยอิสระ`** สำหรับพูดส่งคำถามได้ทันทีโดยไม่ต้องเรียกชื่อ
* 💾 **ความจำบริบทสะสม (Persistent Memory):**
  * ออโต้เซฟบทสนทนาต่อเนื่องข้ามวัน เปิดโปรแกรมมาใหม่จำต่อได้ทันที
  * หลอดนับจำนวนประโยคและโทเคนสะสมสดบนหน้าจอ
  * ปุ่ม **`💾 เซฟความจำแยกไฟล์`** และ **`📂 โหลดความจำ`** ตามตัวละคร/บิลด์
* 🔗 **ค้นหาบิลด์สดจากเว็บ Maxroll:**
  * ถามหาบิลด์ ระบบจะวิ่งไปดึงบิลด์เมต้าล่าสุดจาก `maxroll.gg` ตามอาชีพที่กำลังคุยอยู่มาสรุปให้ทันที
  * ปุ่ม **`🔗 ดูลิงก์เว็บ/บิลด์`** สำหรับกดคลิกเปิดอ่านไกด์ฉบับเต็มบนเว็บ
* 📸 **แคปหน้าจอวิเคราะห์อัตโนมัติ (~100ms):** เมื่อมีคำสั่งเสียงเกี่ยวกับภาพหน้าจอ เช่น *"ดูหน้าจอ"*, *"บอสตัวนี้"*, *"ไอเทมนี้"*
* 🔄 **ระบบเช็กอัปเดตอัตโนมัติ:** มีปุ่ม **`🔄 เช็กอัปเดต`** บนหัวโปรแกรม แจ้งเตือนเมื่อมีเวอร์ชันใหม่บน GitHub

## 🛠️ วิธีรันจาก Source Code (สำหรับนักพัฒนา)

1. Clone โปรเจกต์:
```bash
git clone https://github.com/aircombobreaker-del/poe-jarvis-companion.git
cd poe-jarvis-companion
```

2. สร้าง Virtual Environment และติดตั้ง Dependencies:
```bash
python3 -m venv .venv
source .venv/bin/activate  # บน Windows ใช้: .venv\Scripts\activate
pip install -r requirements.txt
```

3. รันโปรแกรม:
```bash
python main.py
```

4. หรือแพ็กเป็นไฟล์แอป (.exe / .app):
```bash
python build_app.py
```
